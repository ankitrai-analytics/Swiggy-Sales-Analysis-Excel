# Swiggy Sales Analysis Dashboard – Excel

## Project Overview

This project focuses on analyzing Swiggy sales data using Microsoft Excel. An interactive dashboard was developed to monitor sales performance, understand food category preferences, compare geographical sales distribution, and analyze trends across different time periods.

The project demonstrates the use of Excel data analysis and visualization features to convert raw data into meaningful business insights.

## Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Interactive Slicers
- Excel Dashboard Design
- Data Analysis and Visualization

## Key Performance Indicators (KPIs)

The dashboard displays the following metrics:

| KPI | Value |
|---|---:|
| Total Sales | ₹53.01M |
| Average Rating | 4.34 |
| Rating Count | 5.59M |
| Total Orders | 197.43K |
| Average Order Value | ₹268.51 |

## Dashboard Features

### 1. Sales Trend Analysis
- Monthly Sales Trend
- Daily Sales Trend
- Weekly Sales Trend

### 2. Category Analysis
- Sales by Food Type
- Comparison of Veg and Non-Veg sales

### 3. Geographical Analysis
- Sales by State
- Top 5 Cities by Sales

### 4. Quarterly Performance
- Quarterly Sales
- Average Rating
- Total Orders

## Interactive Filters

The dashboard includes interactive slicers for:
- Months
- Category
- Restaurant Name

These filters allow users to explore sales performance across different selections.

## Workbook Structure

The Excel workbook contains three worksheets:

1. **Swiggy Data** – Original dataset.
2. **Analysis Sheet** – Data analysis and supporting calculations.
3. **Dashboard** – Interactive sales dashboard.

## Key Observations

Based on the displayed dashboard:

- Total sales amount to ₹53.01 million.
- Non-Veg sales contribute approximately 65% of food-type sales, while Veg contributes 35%.
- Bengaluru leads the displayed Top 5 Cities by Sales with approximately ₹3.46 million.
- Q2 records the highest quarterly sales among the three quarters displayed, at approximately ₹19.9 million.
- Saturday has the highest sales among the displayed daily sales values.

## Project Objective

The objective of this project is to demonstrate practical Excel skills in data analysis, KPI reporting, PivotTable-based analysis, interactive dashboard creation, and business performance visualization.

## Conclusion

This project demonstrates how Microsoft Excel can be used to organize, analyze, and visualize sales data through interactive dashboards, helping users understand business performance and identify sales trends.
